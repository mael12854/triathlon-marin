Espace admin

Encore une étape pour pouvoir modifier

Vous pouvez tout consulter, mais pas encore enregistrer : il faut relier un espace de stockage Vercel (aucune clé à copier).

  1. Dans Vercel, ouvrez le projet triathlon-marin → onglet Storage.
  2. Create Database → Blob → nom au choix → Create, puis reliez-le au projet (Connect). Si on vous demande l'accès, choisissez Public.
  3. Onglet Deployments → … sur le dernier → Redeploy.
